# Exploratory Data Analysis with NumPy

## Overview
This repository contains a collection of beginner-to-intermediate data analysis projects utilizing Python and the NumPy library. The notebooks demonstrate practical approaches to data cleaning, statistical analysis, and finding correlations across three distinct datasets.

## Technologies Used
* **Language:** Python
* **Libraries:** NumPy
* **Environment:** Jupyter Notebook

## Projects Included

### 1. Employee Analysis (`employeeanlysis.ipynb`)
Analyzes HR data to uncover insights regarding employee compensation and experience.
* **Key Operations:** Filtered high-earning employees (top 10%), calculated the correlation between years of experience and monthly income, and analyzed salary hikes.

### 2. Supermarket Sales Analysis (`supermarket.ipynb`)
Examines transactional data from different supermarket branches to understand sales trends.
* **Key Operations:** Calculated the coefficient of variation to check data consistency, identified the top 5% of customers by sales volume, and compared average revenue between the 'Alex' and 'Cairo' branches.

### 3. Student Performance Record (`student_record_analysis.ipynb`)
Evaluates academic performance across math, reading, and writing subjects.
* **Key Operations:** Computed aggregate scores, calculated the correlation between reading and writing capabilities, and identified the threshold for the top 5% of performing students.
